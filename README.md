Weather App Demo — это веб-приложение для просмотра текущей погоды и прогноза по выбранному городу.  
Приложение получает данные из внешнего погодного API и отображает пользователю температуру, влажность, скорость ветра и погодные условия в удобном интерфейсе.  
Проект создан для изучения работы с JavaScript, HTTP-запросами и внешними API.

## Стек

- JavaScript
- CSS
- HTML

## Локальный запуск

```bash
# Клонировать репозиторий
git clone https://github.com/mikitaglv/weather-app-demo.git

# Перейти в папку проекта
cd weather-app-demo

# Установить зависимости
npm install

# Запустить проект
npm run dev
```
После запуска приложение будет доступно по адресу:  
`http://localhost:5173`
